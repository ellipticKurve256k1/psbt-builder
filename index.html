Esplora Privacy Warning

      

      

        

          Continuing sends up to 200 receiving and 200 change addresses to the public Blockstream Esplora API. Blockstream can observe your IP address, correlate these addresses as one wallet, and infer balances, transaction history, and UTXOs.
        

        

          Your descriptor, xpub, and private keys remain in this browser and are not sent.
        

        
Using a funded row’s UTXOs as inputs makes an additional Esplora request for that address’s current outpoints.

        
Select OK to continue, or Cancel to return to the PSBT Builder without making an Esplora request.
